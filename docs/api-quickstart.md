# HTTP API walkthrough

The public API uses Connect's JSON protocol over ordinary HTTP. These examples use the local credentials generated by `make setup`.

```sh
make setup
set -a
source .env.local
set +a
export MEMJEV_URL="$MEMJEV_E2E_API_URL"
export MEMJEV_TOKEN="$MEMJEV_E2E_TOKEN"
```

Use a new idempotency key for each logical operation. Keep the same key when retrying that operation.

## Retrieve advisory guidance

```sh
curl --fail-with-body --silent --show-error \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $MEMJEV_TOKEN" \
  -H "Idempotency-Key: retrieve-$(openssl rand -hex 12)" \
  --data '{
    "task": "write a hello file",
    "tools": [{"name": "quickstart_print", "contractVersionId": "'"$MEMJEV_QUICKSTART_CONTRACT_ID"'"}],
    "harness": {"name": "my-agent", "version": "1"},
    "riskClass": "RISK_CLASS_LOW",
    "latencyClass": "LATENCY_CLASS_INTERACTIVE",
    "maxCandidates": 5
  }' \
  "$MEMJEV_URL/memjev.v1.RetrievalService/Retrieve"
```

`RETRIEVAL_DISPOSITION_SELECTED` includes an advisory `plan` whose nodes list the procedure's `steps`. Preserve its `injectionId` and `taskExecutionId`. `plan.advisoryOnly: true` means the routine is not promoted yet; see [unpromoted plans](agent-integration.md#unpromoted-plans-and-promotion). `RETRIEVAL_DISPOSITION_ABSTAINED` means the agent should proceed without recalled guidance. In local development the first retrieval activates the default serving configuration automatically. Elsewhere, a clean tenant reports unavailable retrieval configuration until an operator activates one or sets `MEMJEV_RETRIEVAL_AUTO_ACTIVATE=true`.

## Ingest the resulting trace

```sh
curl --fail-with-body --silent --show-error \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $MEMJEV_TOKEN" \
  -H "Idempotency-Key: ingest-$(openssl rand -hex 12)" \
  --data '{
    "clientTraceId": "agent-run-01",
    "harness": "my-agent",
    "harnessVersion": "1",
    "task": "write a hello file",
    "events": [{
      "clientEventId": "tool-call-01",
      "occurredAt": "2026-09-21T00:00:00Z",
      "kind": "EVENT_KIND_EXECUTE",
      "toolName": "quickstart_print",
      "toolVersion": "1.0.0",
      "fields": [{"name": "command", "stringValue": "printf hello"}],
      "result": {"state": "TOOL_RESULT_STATE_SUCCESS", "exitCode": 0}
    }]
  }' \
  "$MEMJEV_URL/memjev.v1.IngestService/IngestTrace"
```

Save the returned `traceId`.

## Record independently verified outcome evidence

Replace `TRACE_ID`, `INJECTION_ID`, and `TASK_EXECUTION_ID` with values returned by the earlier calls. Omit the last two fields when retrieval abstained.

```sh
curl --fail-with-body --silent --show-error \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $MEMJEV_TOKEN" \
  -H "Idempotency-Key: outcome-$(openssl rand -hex 12)" \
  --data '{
    "traceId": "TRACE_ID",
    "executionId": "agent-run-01",
    "injectionId": "INJECTION_ID",
    "taskExecutionId": "TASK_EXECUTION_ID",
    "evidence": [{
      "clientEvidenceId": "verification-01",
      "class": "EVIDENCE_CLASS_GOAL_PREDICATE",
      "verdict": "EVIDENCE_VERDICT_SATISFIED",
      "predicateId": "quickstart-goal",
      "verifierId": "quickstart-user",
      "verifierVersion": "1",
      "observedAt": "2026-09-21T00:00:01Z"
    }]
  }' \
  "$MEMJEV_URL/memjev.v1.OutcomeService/RecordOutcome"
```

An accepted submission is not automatically a promoted memory. The evidence worker validates the archive, tool contracts, policy, and outcome before synthesizing or explicitly abstaining. These examples use the quickstart's demo tool, `quickstart_print`, whose contract `make setup` registers, so a few seconds later the same retrieval returns the learned routine. For your own tools, register contracts first (see [tool contracts](agent-integration.md#tool-contracts-and-first-run-behavior)).

To act for one person with a service token (`scripts/add-person.sh --service`), add `-H 'Memjev-Subject: alice'` to every request.

## Explain a retrieval

```sh
curl --fail-with-body --silent --show-error \
  -H 'Content-Type: application/json' \
  -H "Authorization: Bearer $MEMJEV_TOKEN" \
  --data '{"retrievalRunId":"RETRIEVAL_RUN_ID"}' \
  "$MEMJEV_URL/memjev.v1.RetrievalService/ExplainRetrieval"
```

Explanation is tenant-scoped and returns recorded candidates, gates, score components, degradation state, and composition facts without replaying provider calls.
