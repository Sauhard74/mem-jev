# Backup and restore

Run `scripts/backup.sh` from a restricted operator host with SurrealDB authentication in `SURREAL_USER`/`SURREAL_PASS`, PostgreSQL authentication in standard `PG*` variables, a configured `mc` source alias, and an `age` recipient. The script exports SurrealDB, mirrors immutable canonical objects, dumps Temporal PostgreSQL, verifies every plaintext component, then writes only an encrypted bundle and checksum to the configured output directory.

Restore into newly created, isolated SurrealDB, archive, and PostgreSQL targets. Set `MEMJEV_RESTORE_EMPTY_TARGET_ATTESTATION` to `empty:<namespace>:<database>:<mc-target>:<postgres-target>` exactly. The restore independently verifies all three targets are empty before mutation, reconstructs required content metadata from validated canonical keys, applies `MEMJEV_RESTORE_ARCHIVE_SSE`/KMS encryption, stops on the first PostgreSQL error, and requires `MEMJEV_RESTORE_HEALTHCHECK_URL` to pass before reporting success.

Schedule backups at least daily and retain one off-host copy. Perform a restore drill before launch and monthly thereafter. `mc mirror` captures current object bytes rather than version history; MemJev canonical object keys are immutable and conditional writes prohibit replacement. Supply the current mode-0400/0600 independent erasure ledger and `memjev-admin` binary to restore; the script replays every tombstone before its final health check. See [tenant erasure](tenant-erasure.md).
